O projeto trata de um modelo de aprendizado de máquina para decidir se, a partir de dados de entrada,
uma pessoa possui doenças cardíacas e o estágio da mesma em caso afirmativo. As técnicas
utilizadas foram Random Forest e Árvore de Decisão.

Importante: o modelo apresentado no projeto não substitui a análise de um médico e serve para fins educativos ou de apoio
em decisões de profissionais.

A base utilizada está no repositório com o nome `heart_disease_uci.csv`, mas pode ser acessada no link:
[Kaggle - UCI Heart Disease Data](https://www.kaggle.com/datasets/redwankarimsony/heart-disease-data/data)

## Heart Disease UCI
Dados clínicos de 920 pacientes que passaram por investigação de doença cardíaca em quatro hospitais: Cleveland, Budapeste, Long Beach e Suíça. Cada registro reúne informações de uma consulta e de exames comuns, como idade, sexo, tipo de dor no peito, pressão arterial, colesterol, eletrocardiograma e teste de esforço. Também informa se o paciente tinha doença cardíaca e em que grau, numa escala de 0 (sem doença) a 4.
